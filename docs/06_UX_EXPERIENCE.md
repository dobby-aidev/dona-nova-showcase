# UX PHILOSOPHY

> Users should never feel **lost.**
> Users should never feel **overwhelmed.**

- Every interaction must reduce cognitive load
- Every click must create value
- Every transition must teach the user something
- The experience should feel like **exploring knowledge** rather than **operating software**
